## The Workflow Command Bar

Dossier is a high-performance, cross-platform command bar developed in Rust. It was designed to bridge the gap between static desktop environments and dynamic, AI-driven workflows.

### Key Features:

- **Rust-Powered Core**: Extremely low latency and memory footprint.
- **Modular Plugin Architecture**: Allows developers to extend functionality with custom scripts and integrations.
- **LLM Integration**: Seamless access to language models directly from the command bar.
- **File Indexing**: Fast, efficient searching across the entire filesystem.
- **Custom Workflows**: Automate repetitive tasks with ease.
