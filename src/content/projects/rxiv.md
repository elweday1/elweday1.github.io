## Reimagining UI Rendering

RXIV is a developmental UI framework that explores the possibilities of VDOM-less rendering. By leveraging the power of RxJS for fine-grained reactivity, RXIV eliminates the overhead typically associated with virtual DOM reconciliation.

### Core Philosophy:

- **VDOM-less**: Direct DOM manipulation driven by state updates.
- **JSX Support**: Familiar developer experience with modern syntax.
- **Fine-Grained Reactivity**: Only the parts of the DOM that depend on a specific piece of state are updated.
- **Performance First**: Optimized for high-frequency updates and complex UI interactions.
